# 🤖 Local AI Chatbot (Free, Offline)

A simple Python chatbot that runs locally using Ollama and LLaMA 3.

## 🚀 Features
- 100% free (no API key required)
- Runs locally on your machine
- Simple terminal-based chat interface
- Easy to extend (UI, voice, memory)

## 🛠️ Tech Stack
- Python
- Ollama (LLaMA 3)
- Requests

## ▶️ How to Run

1. Install Ollama  
https://ollama.com

2. Run model:
ollama run llama3

3. Install dependencies:
pip install -r requirements.txt

4. Run chatbot:
python app.py
